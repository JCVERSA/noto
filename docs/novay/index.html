Quelques étapes.

Installe NoVaY depuis le fichier APK officiel téléchargé depuis GitHub Releases.

01

Appuie sur le bouton APK dans la section téléchargement et attends la fin du transfert.

↓
02

Ouvre le fichier APK

Retrouve le fichier dans les téléchargements de ton téléphone, puis ouvre-le.

↗
03

Autorise l'installation si demandé

Android peut demander d'autoriser temporairement ton navigateur ou gestionnaire de fichiers à installer cette application.

✓
04

✳
